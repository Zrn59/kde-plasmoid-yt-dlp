Panel widget for KDE Plasma 6. Downloads video and audio with its own [yt-dlp](https://github.com/yt-dlp/yt-dlp).

```bash
./install.sh
```

Right-click the panel → **Add Widgets** → **yt-dlp**.

Setup, dependencies, and features: [Docs](docs/en/README.md).
