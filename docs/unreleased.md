# 2.1.0

## English

- Added packages: Ubuntu via `ppa:zrn59/kde-plasmoid-yt-dlp`, Debian 13 for amd64 and arm64, Arch Linux for x86_64 and aarch64. No AUR package, registration is temporarily closed 🥲
- The window shows the widget version. The button next to it checks GitHub for a newer version.
- Check shows the title and duration before a download. For a playlist it shows the number of items.
- Skip sponsors was added to the advanced settings.
- Finished downloads are listed in Recent. A file or its folder can be opened from there.
- The widget settings have a file name template. An empty template keeps the title.
- A link can be dropped on the widget icon. The address is inserted into the field and the download does not start.
- Buttons, lists, and fields show a hint on hover.
- A short title is shown above a yt-dlp error. The error text can be copied.
- An unfinished download is kept across a Plasma restart and continued with Retry.
- YouTube cookies can be taken from a Firefox, Chrome, Chromium, Brave, Edge, or Vivaldi profile.

## Русский

- Добавлены пакеты: Ubuntu через `ppa:zrn59/kde-plasmoid-yt-dlp`, Debian 13 для amd64 и arm64, Arch Linux для x86_64 и aarch64. В AUR пакета нет, регистрация временно закрыта 🥲
- В окне показана версия виджета. Кнопка рядом проверяет, есть ли более новая версия на GitHub.
- Кнопка Check до загрузки показывает название и длительность. Для плейлиста показывает число роликов.
- В расширенных настройках добавлена галочка Skip sponsors.
- Готовые загрузки собраны в список Recent. Из него открывается файл или папка.
- В настройках виджета задаётся шаблон имени файла. Пустой шаблон оставляет название.
- Ссылку можно перетащить на значок виджета. Адрес вставляется в поле, загрузка не начинается.
- У кнопок, списков и полей при наведении показывается подсказка.
- Над текстом ошибки yt-dlp показывается короткий заголовок. Текст ошибки копируется кнопкой.
- Незаконченная загрузка сохраняется при перезапуске Plasma и продолжается кнопкой Retry.
- Cookies для YouTube берутся из профиля Firefox, Chrome, Chromium, Brave, Edge или Vivaldi.
