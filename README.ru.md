Виджет панели для KDE Plasma 6. Качает видео и аудио своей копией [yt-dlp](https://github.com/yt-dlp/yt-dlp).

```bash
./install.sh
```

ПКМ по панели → **Добавить виджеты** → **yt-dlp**.
